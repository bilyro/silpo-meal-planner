Which of Silpo's 40 tools the agent actually uses

All 40 are handed to the model every turn — toolsForAiSdk() reads tools/list at runtime and converts each tool's own JSON Schema, so no argument shape is hard-coded anywhere. This is the audit of which ones it reaches, taken from tool_call_log and a grep of src/ rather than from intent.

For trimming

Every irrelevant tool is one more thing the model can reach for wrongly, and this project already needed a duplicate-call guard. Accuracy is the real argument — the cost saving is about $0.012 per plan.

Against

«All 40 exposed» is part of the pitch, and the section above is evidence it does something real. A judge may well read the tool list.
